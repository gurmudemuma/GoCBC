```
1. SUBMISSION     →  2. INSPECTION  →  3. REVIEW  →  4. CLEARANCE  →  5. EXPORT

   🔵 SUBMITTED       🟠 UNDER_INSP     🟡 UNDER_REV   🟢 CLEARED      ✈️/🚢
```

## ✅ PRE-CLEARANCE CHECKLIST

Before clicking **✅ Clear Declaration**:

### Required Documents (Must Have)
- [ ] Export Permit (ECTA issued)
- [ ] Quality Inspection Certificate (ECTA approved)
- [ ] Phytosanitary Certificate (Ministry of Agriculture)
- [ ] Certificate of Origin (Ethiopian Chamber of Commerce)
- [ ] Commercial Invoice (Exporter to buyer)
- [ ] Packing List (Package details)
- [ ] Bill of Lading (Freight forwarder)

### Conditional Documents (If Applicable)
- [ ] Insurance Certificate (if CIF/CIP incoterm)
- [ ] EUDR Due Diligence Statement (if EU destination)
- [ ] Fumigation Certificate (if required by destination)

### System Validations (Auto-checked)
- [ ] Quality inspection = APPROVED
- [ ] Export permit issued
- [ ] No duplicate declaration
- [ ] Inspection completed (if required)
- [ ] Declaration status = UNDER_REVIEW

## 🚨 COMMON REJECTION REASONS

### Documentation Issues (50%)
- Missing export permit
- Phytosanitary certificate not found
- Invoice discrepancies
- Packing list incomplete

### EUDR Compliance (25% of EU exports)
- GPS coordinates missing
- Deforestation-free cert expired
- Traceability gaps

### Valuation Issues (15%)
- Value doesn't match invoice
- Currency conversion errors
- Duty calculation wrong

### Quality Issues (10%)
- Quality grade mismatch
- Sample test failed
- Expired certificates

## 🔍 INSPECTION SCHEDULING GUIDE

### When to Schedule Inspection?

**ALWAYS Inspect:**
- First-time exporter
- High-value shipment (>$500,000)
- EU destination (EUDR)
- Red-flagged exporter
- Quantity >100,000 kg

**Optional Inspection:**
- Known exporter with good history
- Standard shipment
- Documentary review sufficient

**Skip Inspection:**
- Authorized Economic Operator (AEO)
- Green lane exporter
- Emergency humanitarian shipment

### Inspection Types Quick Reference

| Type | Duration | Use Case |
|------|----------|----------|
| **Documentary** | 2 hours | Desk review only |
| **Standard Physical** | 4 hours | Visual check + samples |
| **EUDR Enhanced** | 1 day | Full traceability verification |
| **Risk-Based** | 6 hours | Targeted specific checks |
| **X-Ray** | 3 hours | Container scanning |
| **Full Container** | 8 hours | Complete unload + check |

## 💡 PRO TIPS

### Tip 1: Auto-Fill is Your Friend
When you enter a **Shipment ID** in any form, the system automatically fetches:
- ✅ Exporter ID
- ✅ Quantity
- ✅ Value
- ✅ Destination
- ✅ EUDR status
**Watch for green backgrounds** = auto-filled data

### Tip 2: Check Phyto First
Before clearing, **always verify** phytosanitary certificate exists.
**System will warn you** but it's your responsibility!

### Tip 3: EUDR = Extra Time
If you see **🇪🇺 EUDR Compliant** checked:
- Allow **6.5 days** average
- Verify GPS coordinates
- Check deforestation-free cert
- Review full traceability

### Tip 4: Use Audit Trail
Stuck? Confused about a declaration?
Click **📋 Audit Trail** to see complete history:
- Who did what
- When they did it
- What documents were uploaded
- Status changes

### Tip 5: Air Freight Priority
Look for ✈️ **Air Freight** indicator:
- **24-hour clearance target**
- **Process immediately**
- Skip non-essential checks
- Coordinate with airport customs

## 🆘 TROUBLESHOOTING

### "System can't find shipment"
→ Verify Shipment ID format (SHIP followed by numbers)
→ Check if shipment exists in blockchain
→ Contact exporter for correct ID

### "Declaration already exists"
→ Search for existing declaration (CD-{ShipmentID})
→ Modify existing instead of creating new
→ Use Audit Trail to see who created it

### "Missing export permit"
→ Verify with ECTA portal
→ Check uploaded documents
→ Contact ECTA officer for verification

### "EUDR validation failed"
→ Check GPS coordinates format
→ Verify deforestation-free cert is not expired
→ Contact EUDR specialist (Officer Tigist, ext 2202)

### "Can't clear - status wrong"
→ Status must be "UNDER_REVIEW" to clear
→ If "UNDER_INSPECTION", wait for completion
→ If "SUBMITTED", schedule inspection first
