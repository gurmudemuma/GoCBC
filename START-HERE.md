## 🆘 Troubleshooting

### Still seeing ECTA portal?
1. Make sure you used clear-storage.html
2. Or manually: F12 → Application → Local Storage → Clear
3. Login again

### UI not ready?
Wait for "Ready in" message in terminal

### Wrong password?
- Admin: `admin123` (not `password123`)
- Others: `password123`
