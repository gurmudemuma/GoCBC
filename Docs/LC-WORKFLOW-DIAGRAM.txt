⭐ FOREX ALLOCATION (Step 5)
   • Added to comply with Ethiopian NBE regulations
   • MANDATORY before shipment
   • Enforces 30-50% forex retention in FCY
   • Blockchain-recorded for NBE audit

⭐ DUAL PAYMENT SPLIT (Step 13)
   • 50% USD retained in FCY account
   • 50% converted to ETB at official rate
   • Automatic compliance enforcement
   • Immutable audit trail

⭐ BLOCKCHAIN INTEGRATION
   • All steps recorded immutably
   • Smart contract validation
   • Multi-party transparency
   • Automated NBE reporting

SYSTEM IMPLEMENTATION NOTES
═══════════════════════════════════════════════════════════════════════════════════

FRONTEND: Banks Portal
  └─ Payment Methods Tab
      └─ Letter of Credit Sub-tab
           • Step 1-3: LC Request → Approval → Issuance
           • Step 4: Navigate to Forex Tab
  └─ Banking Operations Tab
      └─ Forex Allocation Sub-tab ⭐
           • Step 5: Allocate Forex
           • View all forex requests
           • Set rates and retention
  └─ Back to Payment Methods
      └─ Letter of Credit Sub-tab
           • Step 6-8: Shipment → Documents → Verification
           • Step 9-13: Payment Release → Settlement

BACKEND: API Endpoints
  • POST /api/v1/banking/lc/:lcID/issue (auto-creates forex request)
  • GET  /api/v1/forex
  • POST /api/v1/forex/allocate
  • POST /api/v1/forex/utilize
  • POST /api/v1/payments/settle

BLOCKCHAIN: Chaincode Functions
  • RequestForex(forexID, contractID, exporterID, amount, currency)
  • AllocateForex(forexID, lcID, amount, rate, retention, officer, ref, expiry)
  • UtilizeForex(forexID, utilizedAmount)
  • QueryAllForex()
